# 💣 로켓단 폭탄 돌리기

아이패드 하나를 가운데 두고 **둘에서 넷이 둘러앉아** 즐기는 폭탄 돌리기.
자기 차례를 끝내고 옆으로 폭탄을 넘긴다. 시간이 다 되면 들고 있는 사람이 터진다.

**두 가지 버전**이 있다 — 앱을 열면 고른다.

**[▶ 바로 플레이](https://ian939.github.io/rocket-bomb/)** · 인터넷 없이도 동작 (한 번 열어두면 됨)

---

## 두 가지 버전

| | 🔢 숫자 퀴즈 | 💬 끝말잇기 |
|---|---|---|
| **하는 일** | 문제를 풀어서 넘긴다 | 말로 이어가고 PASS 를 누른다 |
| **화면** | 문제 + 보기 4개 | 큰 PASS 버튼 하나 |
| **판정** | 앱이 맞는지 본다 | **사람끼리 본다** — 패드는 시간만 잰다 |
| **목숨** | 아이 턴별 2개 / 어른 누적 2개 | 없음 |
| **터지는 때** | 시간 만료 · 두 번 틀림 | 시간 만료 |

끝말잇기는 판마다 **주제**를 하나 뽑는다 (먹는 것 · 동물 · 나라 · 직업 …). 아이가 섞여 있으면 일곱 살이 아는 주제 중에서만 고른다. 주제는 각 사람 앞에 그 사람이 읽을 방향으로 뜬다.

---

## 어떻게 노나

패드를 식탁 가운데 두고 둘러앉는다. 자기 차례가 되면 **자기 앞 구역만 밝아지고**, 문제가 그 사람 쪽으로 돌아간다. 네 개의 보기 중 하나를 누른다.

**2~4명**이 할 수 있고, 인원에 맞게 화면이 나뉜다.

| 인원 | 배치 |
|---|---|
| 2명 | 위아래로 마주보고 |
| 3명 | 위에 둘, 아래에 하나 (아래가 넓다) |
| 4명 | 네 귀퉁이 |

| | |
|---|---|
| **맞히면** | 다음 사람에게 폭탄이 넘어간다 |
| **틀리면** | 경고 — 같은 자리에서 새 문제 |
| **또 틀리면** | 💥 |

### 아이와 어른이 같은 판에서

문제 난이도가 사람마다 다르다. 일곱 살과 어른이 대등하게 겨룰 수 있다.

| | 아이 (7~8살) | 어른 |
|---|---|---|
| **문제** | `7 + 5 = ?` · `13 − 4 = ?` · `6 + ? = 10` | 난이도 3단계 (아래) |
| **목숨** | 2개, **매 턴 초기화** | 2개, **판 전체 누적** |
| **푸는 시간** | 3~5초 | 5~12초 |

어른은 서로 다른 턴에서 한 번씩만 틀려도 진다. 아이는 한 턴에 두 번 틀려야 진다.

### 어른 난이도 3단계

설정에서 고른다. 기본은 3단계.

| 단계 | 문제 | 목표 시간 |
|---|---|---|
| **1** | `47 + 28 = ?` · `81 − 27 = ?` · `25 + 44 + 27 = ?` | 5~7초 |
| **2** | `7 × 8 = ?` · `8 × 4 + 43 = ?` · `35 × 4 = ?` | 6~9초 |
| **3** | `23 × 17 = ?` · `487 ÷ 13 의 나머지는?` | 8~12초 |

암산이 약한 어른이나 큰 아이가 섞이면 1·2단계로 낮춘다.

### 남은 시간은 보이지 않는다

한 판 길이를 **1분 · 2분 · 3분** 중에서 고른다 (기본 2분). 다만 고른 값 그대로가 아니라 **±20초 안에서 흔들린다** — 2분을 고르면 실제로는 1분 40초에서 2분 20초 사이. 대략 얼마인지는 알되 정확히 언제 터질지는 모른다.

남은 시간은 화면에 표시되지 않고, 대신 **똑딱 소리가 점점 빨라진다.**

| 남은 시간 | 똑딱 | 화면 |
|---|---|---|
| 100~50% | 느긋하게 | — |
| 50~25% | 빨라짐 | — |
| 25~10% | 조급하게 | 가장자리가 붉게 맥동 |
| 10~0% | 다급하게 | 맥동이 거세짐 |

언제 터질지 몰라야 서두른다.

## 실행

정적 파일뿐이라 서버가 필요 없다. 다만 Service Worker는 `file://`에서 동작하지 않으므로 로컬 서버로 여는 편이 좋다.

```bash
python -m http.server 8777
# http://localhost:8777
```

아이패드에서는 사파리로 열고 **홈 화면에 추가**하면 주소창 없이 전체 화면으로 뜬다.

## 만듦새

바닐라 JS. 빌드 단계도 의존성도 없다.

```
index.html
css/  lock.css      패드 터치 잠금 (확대·복사 차단)
      game.css
js/   lock.js       ← 가장 먼저 로드되어야 한다
      quiz.js       문제 생성
      audio.js      WebAudio 합성음
      game.js       규칙과 상태
      ui.js         화면
assets/             캐릭터 4종 + 폭탄 + 폭발 (512px, 합계 95KB)
sw.js               오프라인 캐시
```

### 짚어둘 것

**패드 터치 잠금** — 아이가 쓰는 화면이라 확대·복사·길게 눌러 뜨는 메뉴를 전부 막았다. viewport·CSS·JS 세 겹으로 건다. 한 번 확대되면 아이 혼자 되돌리지 못해 놀이가 거기서 끊기기 때문이다. 일반 웹사이트에는 이렇게 하지 않는다 — 확대는 접근성 기능이다.

**화면 회전** — 마주 앉은 사람의 구역은 180° 돌아간다. `transform: rotate()`를 쓰되, 90°/270° 자리는 가로세로가 바뀌므로 실제 픽셀 크기를 CSS 변수로 넣어 맞춘다.

**인원별 배치** — 구역은 `grid-area`를 CSS 변수로 받아 자리를 잡는다. 인원마다 구역 모양이 달라지므로 폭탄은 좌표를 고정하지 않는다.

**폭탄 자리** — 폭탄은 지금 차례인 구역의 **머리띠에 있는 빈 칸(`.bomb-slot`) 위**로 간다. 처음엔 화면 가운데에서 그 구역 쪽으로 다가가게 했는데, 문제와 보기가 바로 그 안쪽에 있어 숫자를 덮었다. 귀퉁이로 옮겨도 보기 2×2가 구역을 꽉 채워 늘 무언가를 가렸다. 머리띠는 문제·보기 바깥이라 안전하다. 다만 폭탄을 그 칸 *안에* 넣지는 않는다 — `buildQuads`가 구역을 다시 그릴 때 같이 지워져 폭발 연출에서 폭탄을 잃는다. 칸의 위치만 재서 그 위로 옮긴다.

**모드 전환 순서** — 버전이 바뀌면 구역 안의 내용 자체가 달라진다(보기 4개 ↔ PASS 하나). 그래서 `startRound()`가 모드를 정한 직후 `roundSetup` 이벤트로 **구역을 먼저 다시 그리고**, 그 다음에 첫 문제를 낸다. 순서가 뒤집히면 PASS 버튼만 있는 구역에 문제를 쓰려다 터진다.

**타이머는 절대 시각 기준** — 남은 초를 세는 변수가 아니라 "끝나는 시각"을 들고 있다. 패드를 잠그거나 앱을 전환했다 돌아와도 정확하다. 화면이 가려지면 판이 멈추고 "계속하기"가 뜬다 — 실수로 홈 버튼을 눌러 터지면 억울하니까.

**iOS 소리** — WebAudio는 사용자가 실제로 누른 순간 안에서 `resume()`해야 열린다. 시작 버튼 핸들러에서 언락한다. 이게 없으면 첫 판이 통째로 무음이 된다.

**진동은 없다** — iPadOS 사파리에 `navigator.vibrate`가 없다. 폭발은 소리와 화면 흔들기로만 전한다.

**흔들기는 래퍼에** — `body`에 `transform`을 걸면 안쪽 `position: fixed`가 깨진다. `#shake-root`에만 건다.

**캐시 전략** — 화면과 코드는 network-first(인터넷이 되면 새것, 안 되면 캐시), 그림은 cache-first. 전부 cache-first로 두면 고친 내용이 이미 다녀간 기기에 영영 안 닿는다. 내용을 고치면 `sw.js`의 `CACHE` 버전을 올린다.

### 아이를 위해 정한 것

- 누르는 곳은 최소 **88×88px** — 회전된 상태에서 누르므로 44px의 두 배로 잡았다
- 하트·✓ 같은 표시는 **모서리에** 둔다. 문제나 그림 위에 겹치면 자기가 뭘 했는지 못 본다
- 폭발 플래시는 **3회 이하** (광과민성 발작 예방). 설정에서 끌 수 있다
- **순한 폭발** 토글 — 소리와 흔들림을 절반으로. 어린 동생이 무서워하면
- 색으로만 알리지 않는다 — 정답은 초록 + ✓, 오답은 붉은색 + ✕ + 흔들림
- 누적 점수도 순위도 없다. 져도 바로 다음 판으로 간다

## 설정

| 항목 | 고를 수 있는 것 |
|---|---|
| **버전** | 숫자 퀴즈 · 끝말잇기 (시작 화면) |
| **몇 명이서** | 2명 · 3명 · 4명 |
| **어른 난이도** | 1 · 2 · 3 (기본 3, 숫자 퀴즈에서만) |
| **한 판 시간** | 1분 · 2분 · 3분 (±20초 흔들림) |
| 🔊 소리 | 똑딱·정답·폭발음 |
| ⚡ 번쩍임 | 폭발 시 붉은 플래시 (끄면 부드러운 페이드) |
| 🧸 순한 폭발 | 소리와 흔들림을 절반으로 |

마지막에 쓴 멤버 구성과 설정은 저장되어 다음에 그대로 뜬다. 인원을 줄였다 늘려도 앞서 적은 이름이 살아 있다.

## 만든 이야기

[PRD.md](PRD.md)에 기획 과정과 결정 근거가 있다. 원래 PokéAPI로 포켓몬 능력치 퀴즈를 낼 생각이었지만, 아이가 글을 읽느라 시간을 뺏기지 않도록 **순수 숫자 문제**로 정리하면서 API를 뺐다. 그 덕에 네트워크 없이도 돌아간다.

캐릭터 그림은 직접 생성한 것이다.
